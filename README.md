# Bkash-transaction-analysis
## 📋 Descriptionw
This project presents a deep dive into a simulated dataset of bKash transactions. The goal was to analyze financial patterns, service charge distributions, and net revenue across different regions and customer segments in Bangladesh using Microsoft Excel.

Key Insights (KPIs)
Based on the analysis, the following metrics were highlighted:
No.Transaction: 3781
Total Revenue: TK.1.597 M
Amount of Transaction: 267.759
Total Sevice Charge: 2.278
Total commission Earned: .680 M

Transaction Types: Analysis of Cash Out, Send Money, Payment, Mobile Recharge, and Cash In.

Regional Performance: Revenue breakdown for major cities like Dhaka, Khulna, Rajshahi, and Sylhet.

Customer Segmentation: Analysis of Net Revenue based on Customer Tenure (1 to 8 years).

Financial Metrics: Calculation of Service Charges, Agent Commissions, and Net Revenue for the platform.

Merchant Analysis: Revenue distribution across various merchant categories including Pharmacy, Retail, Grocery, and Restaurants.

Dashboard & Visualizations
The project utilizes Excel Pivot Tables and Slicers to provide an interactive experience:

Monthly Trends: Visualizing transaction volume and amount from January to December.

Sender Type Analysis: Comparing performance between Agent, Personal, and Merchant accounts.

Interactive Filters: Users can filter data by Location, Transaction Type, and Date.

Tools Used
Microsoft Excel: Data structuring, cleaning, and advanced Pivot Table reporting.

Data Modeling: Implementation of financial formulas to calculate net margins.

How to Explore
Download the bkash_advanced_dummy_data.xlsx file.

Open it in Microsoft Excel.

Go to the 'Pivot Table' sheet to interact with the data and see the summarized reports.
